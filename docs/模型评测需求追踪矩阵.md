# 模型评测需求追踪矩阵

> 对比基线：《模型评测原始需求》；产品需求：《PRD-模型评测》；交互入口：模型评测下的评测任务、评测数据、模型对比、配置方案、评测文档。

## 结论

本轮审查发现的状态术语不一致、假下载、假在线调试、仅校验扩展名、数据集与指标不随任务联动、指标权重不可配、流程依赖不受约束、文档只搜索目录名等缺口，已在交互原型和 PRD 中完成调整。前端原型已具备可验证行为；生产验收仍以真实后端 API、队列、Worker、对象存储、指标执行器、报告服务和 RBAC/审计服务接入为前置条件，不能用演示数据代替。

## 发布阻断项

- 页面、API 和文档出现不一致的状态枚举。
- 连接测试、在线调试、报告或导出使用固定成功文案而没有真实请求/文件。
- 校验失败的数据集仍能被任务引用，或跨资源组读取任务、数据集、报告。
- 模型对比未统一数据集版本、任务和指标量纲。
- 指标与流程配置无法回显执行版本，导致结果不可复现。
- 任一写操作未执行权限校验或未记录审计事件。
