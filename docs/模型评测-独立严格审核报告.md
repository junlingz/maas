## 3. P0 问题

### P0-01 没有模型评测后端

项目只有 Vite/React 的 `dev` 和 `build` 脚本，没有任务 API、执行队列、评测 Worker、结果存储或数据库。

- 证据：`/Users/a1/Documents/Z/08超大规模/原型/maas/package.json:6`
- 证据：`/Users/a1/Documents/Z/08超大规模/原型/maas/vite.config.ts:19`
- 影响：无法真实创建、运行、监控或完成模型评测任务。
- 最低成本修复：提供最小后端服务，至少实现任务创建、查询、停止、删除、结果及报告接口，并使用异步队列执行任务。

### P0-02 开始、停止、删除只修改前端状态

“开始测评”只生成前端对象并写入 `localStorage`；“停止”直接修改 React 状态；“删除”只移除浏览器中的任务记录。

- 证据：`/Users/a1/Documents/Z/08超大规模/原型/maas/src/app/components/ModelEvaluation.tsx:645`
- 证据：`/Users/a1/Documents/Z/08超大规模/原型/maas/src/app/components/ModelEvaluation.tsx:1286`
- 证据：`/Users/a1/Documents/Z/08超大规模/原型/maas/src/app/components/ModelEvaluation.tsx:1384`
- 影响：不满足后台执行队列、停止指令及数据库删除要求。
- 最低成本修复：三个操作分别调用真实后端 API，并以服务端返回状态为准刷新页面。

### P0-03 数据集没有真实上传、存储和隔离

文件通过 `file.text()` 在浏览器读取，系统只保存文件名和元数据；共享权限只修改本地字段，没有数据文件存储或授权关系。

- 证据：`/Users/a1/Documents/Z/08超大规模/原型/maas/src/app/components/EvaluationData.tsx:129`
- 证据：`/Users/a1/Documents/Z/08超大规模/原型/maas/src/app/components/EvaluationData.tsx:205`
- 证据：`/Users/a1/Documents/Z/08超大规模/原型/maas/src/app/components/evaluationDatasetStore.ts:25`
- 影响：不满足自定义数据集接入、团队共享和数据安全要求。
- 最低成本修复：实现文件上传、对象存储、数据集记录、异步校验及 ACL 授权表。

### P0-04 用户权限和数据隔离未实现

评测模块没有当前用户、角色、资源组或授权上下文，创建人和资源组为硬编码值。

- 证据：`/Users/a1/Documents/Z/08超大规模/原型/maas/src/app/components/ModelEvaluation.tsx:667`
- 证据：`/Users/a1/Documents/Z/08超大规模/原型/maas/src/app/components/EvaluationData.tsx:230`
- 影响：任何用户隔离、资源组隔离、只读或编辑权限都无法得到服务端保障。
- 最低成本修复：所有任务和数据集查询必须由服务端根据用户、资源组和 ACL 过滤。
