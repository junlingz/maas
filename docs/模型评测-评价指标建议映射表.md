# 模型评测任务与评价指标建议映射表

## 一、用途

本表是“评价指标建议”的唯一业务数据源。系统根据数据集的适用任务自动生成建议指标，不允许上传者手动选择。该建议仅用于公开数据集详情展示，以及创建评测任务未选择流程模板时的默认指标推荐；选择流程模板后，以模板中的指标和权重为准。

## 二、任务与指标映射

| 模型类型 | 任务编码 | 适用任务 | 建议指标编码 | 页面展示名称 |
|---|---|---|---|---|
| 语言模型 | `text_understanding` | 文本理解 | `accuracy, f1` | Accuracy、F1 |
| 语言模型 | `question_answering` | 问答 | `accuracy, f1` | Accuracy、F1 |
| 语言模型 | `reasoning` | 逻辑推理 | `accuracy` | Accuracy |
| 语言模型 | `code_generation` | 代码生成 | `pass_at_1` | Pass@1 |
| 多模态模型 | `image_captioning` | 图文描述 | `bleu, rouge, meteor` | BLEU、ROUGE、METEOR |
| 多模态模型 | `visual_question_answering` | 视觉问答 | `accuracy` | Accuracy |
| 多模态模型 | `document_parsing` | 文档解析 | `accuracy, f1` | Accuracy、F1 |

## 三、本映射使用的指标编码

| 指标编码 | 页面展示名称 | 状态 |
|---|---|---|
| `accuracy` | Accuracy | 启用 |
| `f1` | F1 | 启用 |
| `bleu` | BLEU | 启用 |
| `rouge` | ROUGE | 启用 |
| `meteor` | METEOR | 启用 |
| `pass_at_1` | Pass@1 | 启用 |

## 四、系统规则

- 用户选择或修改适用任务后，系统立即根据本表刷新“评价指标建议”，该字段只读。
- 一个数据集适用多个任务时，按任务在本表中的顺序合并指标并去重，保留指标首次出现的顺序。
- 公开数据集详情必须展示“评价指标建议”；未命中映射时显示“暂无评价指标建议”。
- 公开数据集上传和编辑页面展示只读建议结果，不提供指标选择控件。
- 自定义数据集上传页面不展示该字段。
- 创建评测任务未选择流程模板时，复用本表生成默认指标并自动等分权重。
- 创建评测任务选择流程模板后，模板指标和权重覆盖本表建议。
- 停用或删除推荐指标前必须先从本表移除；`关键词匹配率` 仅作为配置方案中的可选匹配类指标，不进入本表的默认推荐范围。
- 映射调整后对后续页面查询和新建评测任务生效，不修改历史任务已固化的指标和权重。

## 五、待算法确认

- 文本理解使用 Accuracy、F1 是否可以覆盖当前评测目标。
- 问答任务是否只使用 Accuracy、F1。
- 逻辑推理使用 Accuracy 是否足够。
- 图文描述是否同时支持 BLEU、ROUGE、METEOR。
- 视觉问答现阶段仅使用 Accuracy 是否合理。
- 文档解析使用 Accuracy、F1 是否合理，或是否需要任务专用指标。
